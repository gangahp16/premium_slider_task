# Policy Premium Filter

A full-stack application to display insurance policies and filter them by premium range.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- HTML, CSS, JavaScript

## Features
- Fetch and display policy data from MongoDB
- Filter policies based on premium range
- REST API based backend
- Simple and clean frontend UI

## Setup

### Backend
```bash
cd backend
npm install
node server.js

Frontend
Open frontend/index.html using Live Server or a browser.
API Endpoints
/policies – Fetch all policies
/policies/filter?min=&max= – Filter by premium range
